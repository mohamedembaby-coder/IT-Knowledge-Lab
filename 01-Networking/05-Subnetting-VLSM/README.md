# IPv4 Subnetting & Variable Length Subnet Mask (VLSM)

> **Category:** Networking
> **Level:** Beginner → Intermediate
> **Status:** Draft
> **Certification:** Cisco CCNA 200-301

## Overview

IPv4 Subnetting is the process of dividing a network into smaller logical subnets.
VLSM allows each subnet to have a different size based on business requirements.

## Learning Objectives

- Understand IPv4 addressing
- Convert Decimal/Binary
- Understand CIDR
- Calculate subnet masks
- Design VLSM networks
